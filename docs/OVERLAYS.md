# Crows Chart — overlay reference

Every overlay in the app, with every date it draws. Generated by `npm run docs` from `public/js/catalog.js` on 2026-10-25.

Evidence grades: A — strong · B — medium · C — weak / folklore.

Correlation is not cause. Bitcoin has had only 4 halving cycles, so every pattern here rests on a few examples.
